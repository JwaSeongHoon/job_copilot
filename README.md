# 상담사 코파일럿 (job_copilot)

국민취업지원제도 상담사가 업무매뉴얼을 빠르게 찾아보고 수급자격을 가늠할 수 있게 돕는 RAG 실습 프로젝트입니다. 비개발자도 따라 할 수 있게 단계별 단일 파일 스크립트로 만들었고, `docs/`의 교안과 함께 봅니다.

| 폴더 | 내용 | 교안 |
| --- | --- | --- |
| `hello_rag/` | 가상의 사내 안내서 6개로 RAG의 원리를 익히는 입문 실습 | `docs/교안1_hello_RAG.pptx` |
| `manual_rag/` | 실제 「국민취업지원제도 업무매뉴얼(2026.1)」로 만든 상담 도우미 | `docs/교안2_매뉴얼_RAG.pptx` |

기획 배경과 요구사항은 [`docs/상담사_코파일럿_기획서.md`](docs/상담사_코파일럿_기획서.md)에 있습니다.

## 준비

Python 3.9 이상이 필요합니다.

```bash
pip install -r hello_rag/requirements.txt
```

두 폴더의 `requirements.txt`는 내용이 같습니다(`streamlit`, `scikit-learn`, `anthropic`).

AI 답변을 보려면 Claude API 키가 필요합니다. 환경 변수 `ANTHROPIC_API_KEY`로 넣어 두거나, 앱 왼쪽 사이드바에 직접 입력합니다.

## 실습 1: hello RAG

```bash
cd hello_rag
python 1_search.py        # 1단계: 검색만 해 보기 (API 키 필요 없음)
streamlit run 2_app.py    # 2단계: 검색 + AI 답변 웹 앱
```

- 1단계는 `data/` 폴더의 글을 조각으로 나누고, 질문과 가장 비슷한 조각 3개를 보여 줍니다.
- 2단계는 찾은 조각을 Claude에게 함께 보내 답을 받습니다.
- `테스트질문.txt`에 질문 7개와 정답이 있습니다. 7번은 자료에 없는 내용을 묻는 함정 질문으로, AI가 "자료에서 찾을 수 없습니다"라고 답해야 성공입니다.

## 실습 2: 매뉴얼 상담 도우미

```bash
cd manual_rag
streamlit run 2_app.py
```

화면은 탭 두 개입니다.

- **매뉴얼 Q&A**: 일상적인 말로 물으면 매뉴얼 용어로 바꿔 검색하고, 결론과 근거 위치(`Part > 장 > 절`)를 함께 답합니다.
- **수급자격 판정 가이드**: 나이, 가구원 수, 소득, 재산, 취업 일수를 넣으면 예상 유형(1유형 요건심사형 / 1유형 선발형 / 2유형 / 참여 불가)과 다음에 물어볼 질문을 알려 줍니다.

매뉴얼을 조각으로 바꾼 `manual_chunks.json`이 저장소에 들어 있어서 바로 실행할 수 있습니다.

### 매뉴얼을 직접 변환하려면

매뉴얼 원본(`.hwpx`)은 용량이 커서 저장소에 넣지 않았습니다. 파일을 따로 구해 `manual_rag/` 폴더에 1개만 넣고 실행합니다.

```bash
python 1_convert.py       # .hwpx → manual_chunks.json
```

변환기는 2026.1 매뉴얼의 Part 구성(01~07)에 맞춰져 있습니다. 다른 연도의 매뉴얼을 넣으려면 `1_convert.py`의 `PARTS`와 `2_app.py`의 `MEDIAN_INCOME_2026`(기준 중위소득 표)을 함께 고쳐야 합니다.

## 동작 방식

두 앱 모두 같은 순서로 움직입니다.

1. 자료를 작은 조각으로 나눈다.
2. 조각마다 글자 패턴(TF-IDF, 2~3글자 단위)을 숫자로 바꿔 색인을 만든다.
3. 질문과 가장 비슷한 조각을 고른다.
4. 고른 조각과 질문을 Claude에게 보내 답을 받는다.

벡터 DB나 임베딩 모델 없이 `scikit-learn`만으로 검색합니다.

## 사용할 때 주의할 점

- 이 도구는 상담사 전용 보조 도구입니다. 판정 결과는 **예상 판정**이고, 최종 판단은 상담사가 합니다.
- 매뉴얼에 근거가 없거나 고용센터마다 해석이 다를 수 있는 내용은 "⚠ 팀장 확인 필요"로 표시됩니다.
- 구직자의 이름, 주민등록번호, 연락처는 입력하지 마세요. 판정 가이드에는 수치만 넣습니다.
- `hello_rag/data/`의 회사와 규정은 실습용으로 만든 가상의 내용입니다.
